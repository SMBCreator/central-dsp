## Roadmap (после выхода в прод, приоритезировано)

1. **Identity-граф (UID2/ID5/собственный)** — fallback-цепочка ifa → eids →
   fingerprint для freq caps и audiences. Основа для всего остального.
   Prereq: Go-биддер в проде.
2. **ML bid shading v2** — замена эвристики на модель (win-rate по цене,
   контекстные фичи: партнёр/домен/размер/час). Обучение остаётся офлайн
   (Python), биддер читает факторы — архитектура уже готова.
3. **CTV/OTT** — `imp.video` с подтипами, VAST 4.x, pod bidding. Требует
   video-креативов в модерации и ОРД-маркировки роликов.
4. **Retail Media** — отдельный тип кампаний с товарным фидом (YML),
   sponsored products API для площадок-ритейлеров.
5. **DOOH** — `device.devicetype=8`, аукционы по слотам экранов.
6. **Собственный трейдинг-деск UI** — авто-правила (пейсинг, дневные лимиты
   по win rate), рекомендации ставок.

Правило: ни одна фича из roadmap не стартует до закрытия high-гэпов
`gap_register.md` и cutover Go-биддера.
